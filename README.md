# To-Doey

To-Doey is a responsive to-do list application designed to help users create, track, and complete everyday tasks in a simple and visually organized way.

The project began as a set of high-fidelity mockups and is being developed into a functional application using HTML, CSS, and vanilla JavaScript. The goal of the project is to create a polished app that focuses on a small set of core task-management features and performs them well.

## Features

- Add new tasks through a form
- Prevent empty tasks from being added through form validation
- Mark tasks as complete
- Delete tasks
- Filter tasks by status, such as:
  - All
  - Active
  - Completed
- Display a live summary of how many tasks are left
- Responsive layout for mobile and desktop
- Hover and active states for interactive elements
- Empty, loading, and error states
- Custom To-Doey visual design system

## How It Works

Tasks are stored in a JavaScript array of objects and rendered dynamically to the page. Instead of hardcoding list items into the HTML, the application uses JavaScript to create and update the task list based on the current data.

When a user adds, completes, deletes, or filters a task, the application updates the data and re-renders the interface to reflect the change.

## How to Use

1. Open the To-Doey application.
2. Enter a task into the task input field.
3. Select **Add** to add the task to the list.
4. Mark a task as complete when it is finished.
5. Delete tasks that are no longer needed.
6. Use the task filters to view all, active, or completed tasks.
7. Check the task summary to see how many items are still left to complete.
